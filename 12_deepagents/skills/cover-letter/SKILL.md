# Cover letter

## Goal

A short letter a hiring manager can finish in 60 seconds. It must sound like Aisha, not like a template.

## Steps

1. Read the CV. List the 3 facts that actually match this JD.
2. Read the JD. List the must-have keywords.
3. Write the letter in this shape:
   - Line 1: the role and the company.
   - Body: 2 short paragraphs. Each paragraph is one CV fact tied to one JD need.
   - Close: availability in Dubai and a request to talk.
4. Scan the letter. If any skill, tool, language, or year is not in the CV, delete that sentence.

## Output

Write the final letter to `cover_letter.md`. Do not wrap it in a chatty preface.
